# 无人机运行领域约定

服务面向低空运行、机队运维和合规管理人员。时间字段统一使用带时区的
ISO 8601 字符串（无时区偏移一律拒绝），位置、授权和设备事件应保留来源
时间与接收时间，不能用展示层文字替代结构化状态。

健康接口只表示进程存活，不代表任何飞行或审批业务已经完成。需要落盘的
数据应使用运行时配置指定的位置（`RELEASE_DATA_DIR`），测试不得依赖主机
上的隐藏状态。

## 放行判断

一次放行判断同时考虑：GeoJSON 空域（禁飞/限飞）、带版本的通告、
航点时序计划、机型能力、操作员资质。计划按分段审查：

| 分段类型 | 说明 |
| --- | --- |
| `takeoff` / `landing` | 起降点与垂直剖面 |
| `enroute` / `return` | 航路、返航折线 |
| `hover` | 悬停点与持续时长 |
| `alternate` | 备降路线（人工比对最易漏，必须独立审查） |

每段独立得出 批准/附条件/拒绝，任务结论取最严。拒绝理由与附加条件均为
结构化记录（规则码、空域或通告引用、高度与时间区间），可从任一结论追溯
完整判断过程。

## 稳定规则

- **几何**：经纬度按平面近似（低空小范围足够）；空域为闭集——边界相切、
  触边、压线一律视为进入；垂直范围同为闭区间，恰好压在区顶算冲突。
- **时间**：飞行区间为闭区间，通告与空域的绝对生效窗为半开区间
  `[from, until)`；跨午夜不产生特例；每日时段窗按 `RELEASE_TZ` 解释，
  结束不晚于开始时跨零点回绕，起止相等视为全天。
- **通告版本**：版本号按 id 严格递增，评估只采用决策时刻的最新版本；
  撤回（`op=withdraw`）是一个新版本，使该通告退出后续评估。
- **决策固化**：决策 append-only，快照记录规则版本、空域版本与校验和、
  通告版本、机型与操作员、人工意见（改判必须填写说明，系统结论与最终
  结论分别留存）。
- **复核而非改写**：新通告（发布即生效或定时生效）与已放行计划冲突时，
  只生成待复核条目与提醒；同一（任务, 触发源）不重复生成。复核处理可
  触发重新评估，产生新序号决策，历史决策原样保留。
- **并发**：任务 id 唯一、计划 `(任务, 版本)` 唯一，写操作在
  `BEGIN IMMEDIATE` 事务内完成检查与插入，相同任务的并发提交只有
  一个有效版本。
